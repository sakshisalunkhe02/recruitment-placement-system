# 💼 Recruitment & Placement Management System

A web-based recruitment and placement portal built with **Python**, **Streamlit**, and **MySQL**. It automates campus hiring workflows, allowing candidates to browse and apply for open jobs, recruiters to evaluate applicants, and admins to monitor placement metrics.

---

## 🚀 Features

- **Role-Based Access**: Multi-user registration supporting Candidate, Recruiter, and Admin roles.
- **Job Management**: Recruiters can publish open positions complete with salary ranges, company details, and locations.
- **Smart Job Search**: Candidates can search listings by keyword and filter positions by location.
- **Duplicate-Safe Application Tracking**: Candidates can submit job applications (with duplicate-application prevention) and track real-time status updates (*Applied*, *Shortlisted*, *Rejected*, *Hired*).
- **Recruiter Dashboard**: Recruiters can evaluate applicants and save hiring decisions directly to MySQL.
- **Placement Insights & Stats**: Visual dashboard summarizing system metrics, user role breakdowns, and hiring outcomes.

---

## 🛠️ Tech Stack

- **Frontend / UI**: Streamlit
- **Backend**: Python 3.12+
- **Database**: MySQL 8.0+ (`mysql-connector-python`)
